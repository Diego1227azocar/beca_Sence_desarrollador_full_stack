# Base de Datos Clínica Veterinaria

## Descripción
Proyecto de base de datos relacional desarrollado en PostgreSQL para gestionar la información de una clínica veterinaria.

El sistema permite registrar:
- Dueños de mascotas
- Mascotas
- Profesionales veterinarios
- Atenciones médicas

## Tecnologías
- PostgreSQL
- pgAdmin 4
- SQL
- GitHub

## Estructura del proyecto

database/
- creación de base de datos
- creación de tablas
- inserción de datos
- consultas SQL
- ejemplo de transacción
